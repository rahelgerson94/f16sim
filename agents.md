General coding practices
when updating or adding code:
1. make only the necesary changes:
   1. do not remove comments.
   2. do not remove code or change code thats unrelated to the task given, or ask before doing so.
2. add comments on what you are doing for most things.
3. minimize the use of external libs if a task can be done by using foundational coding practices. For example, for paths, use f-strings rather than created paths objects.  
4. code in camelCase
5. comments in cpp: star comments rather than double slash comments 
6. comments in python: hashtags.
